# Library-Song
**Uma experiência musical interativa diretamente no terminal, desenvolvida em Python.**

## Sobre o projeto
O Library-Song é um projeto desenvolvido em Python que apresenta trechos de músicas diretamente no terminal, utilizando efeitos visuais de digitação, cores e pausas sincronizadas.
A proposta é transformar a reprodução textual de uma música em uma experiência mais dinâmica e interativa, simulando um efeito de karaokê no terminal.

## Funcionalidades
- Exibição de textos com efeito de digitação.
- Personalização de cores para destacar determinados trechos.
- Sincronização de frases com pausas temporizadas.
- Limpeza automática do terminal.
- Atualização dinâmica do texto durante a execução.

## Stack

- **Python** — Linguagem de programação.
- **Time** — Controle de tempo e intervalos.
- **OS** — Manipulação e limpeza do terminal.
- **Rich** — Formatação de textos, cores e efeitos visuais no terminal.

### Pré-requisitos

- Python 3.x instalado.
- Terminal ou prompt de comando.

### Instale a biblioteca Rich

```bash
pip install rich
```

## 🚀 Como executar

1. Clone o repositório:

```bash

```

2. Acesse a pasta:

```bash

```

3. Execute o arquivo Python:

